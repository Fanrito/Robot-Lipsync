# Evidence and Reproducibility

All numerical tables are selected from existing experiment outputs. No result was invented or
regenerated by training for this release. `provenance.json` records relative private-archive
identifiers and SHA256 hashes, not links to bundled full experiments or permission to access them.

| File | Contents | Interpretation |
|---|---|---|
| `syncnet_metrics.csv` | Nine historical 2D/3D evaluations | Separate protocol/model/domain rows; not one leaderboard |
| `robot_flame_metrics.csv` | Five controlled models and two speech models | Weak-target, coordinate-wise errors; different domains |
| `sync2d_val_curves.csv`, `sync2d_test_curves.csv` | 8 val and 8 test clips, 7 offsets each | Recompute AUC/BAcc/Top-1/MAE and plots without weights |
| `speech_v2_descriptor_excerpt.csv` | Two held-out scalar trajectories | Relative host times; no meshes or absolute machine clock |
| `teacher_direct_optimization.csv` | Eight short-clip optimization configurations | Same-input optimization, not held-out learned generalization |
| `refiner_ablation.csv` | 8 held-out utterances, three arms | Original / no-teacher / with-teacher |
| `evidence/*.json` | Selected numeric source records | Source hash mapping in provenance |

## Exact Values and Important Differences

- Earlier real-data AUC: **0.978840877914952** on 54 clips/594 pairs. Threshold tuned on that evaluation set. Legacy offset MAE is **530.976430976431 ms**; it is not the 25 ms result.
- Project full-frame original-weight baseline: AUC **0.9505208333333334**, BAcc **0.8958333333333333**, offset MAE **25.0 ms** on 8 test clips/56 pairs; threshold from 8 val clips.
- Robot-SyncNet v2 on that same full-frame protocol: AUC **0.9427083333333333**, BAcc **0.9270833333333333**, MAE **12.5 ms**. Better localization, not better AUC.
- Strict upstream-crop baseline: AUC **0.4115**, BAcc **0.5208**, MAE **262.5 ms**, rounded from the surviving experiment report. Original raw JSON was not found. This row has lower evidence granularity and no reconstructed extra decimal places.
- Controlled static+temporal: mouth MAE **0.00029786548111587763**, jaw corr **0.9468832253097659**, outer corr **0.9530363544104494**. These verify the prompt's approximate values, but are not the latest speech-model performance.
- Speech-v2 adapted test: mouth MAE **0.0005308961332677833**, jaw corr **0.8295639643325099**, outer corr **0.8411266151865278**, outer amplitude **0.9660965998557132**.

The old `speech_adaptation_final` inspection videos were later recropped without retraining the
checkpoint or recomputing its root metrics. Those mismatched video/target metrics are deliberately
not promoted as the final Speech-v2 result here.

## Aggregation

Simulator descriptor correlations are pooled over the corresponding test frames. Curves in the
excerpt are selected illustrations, not a substitute for those pooled results. Amplitude is P98-P2.
2D AUC is over sequence-offset rows; 3D AUC is over window/context-offset examples. Counts are
provided, but overlapping windows are not independent samples. Categories are inherited from
the archive: older `normal/bilabial/vowel` correspond to newer natural/bilabial_dense/vowel_contrast.

There are no confidence intervals or statistical-significance claims in this release. These are
single-platform research results, not a cross-robot benchmark. `scripts/evaluate_flame.py` reports
**excerpt-only** values when given the bundled curves. Full metric reproduction from raw frames
requires withheld recordings, weights and independently obtained licensed assets.
